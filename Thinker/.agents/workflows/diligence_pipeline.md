# Intelligent Equity Diligence & Outreach Pipeline

This workflow automates the process of identifying investment diligence vectors using NVIDIA Nemotron and initializing primary research lead generation. 

**Required Inputs:**
Whenever the user runs this workflow, ask them to provide 3 Google Sheets URLs containing the equity data.

## Step 1: Initial Setup & Thought Logging
- First, create an artifact in the workspace named `thought_process_log.md`.
- Throughout this workflow, you MUST document your reasoning here. Include:
  - Which tabs were parsed from the sheets and why.
  - The raw rationale generated by the Nemotron model.
  - The final primary diligence questions that need answering.
- Update this log continuously as you progress so the user sees your thought process clearly.

## Step 2: Parse Google Sheets
- Write and run a Python script to temporarily download or read data from the 3 provided Google Sheets URLs. Use the gspread or pandas library depending on the sharing settings.
- For each sheet, parse all the tabs and identify the most updated one by scanning for recent date strings.
- Extract the tabular data from these most recent tabs.
- Document any issues or the final extracted data summary in `thought_process_log.md`.

## Step 3: NVIDIA Nemotron Analysis
- Using the extracted data, write and run a script to query the NVIDIA Nemotron model.
- **Model Details:**
  - Endpoint: `https://integrate.api.nvidia.com/v1/chat/completions` (using the `nemotron-3-super-120b-a12b` model identifier if it follows the OpenAI API library format, or modify as needed based on exact integration schema).
  - API Key: `your-nvidia-api-key` (loaded via NVIDIA_API_KEY environment variable)
- **Prompt Instructions:**
  - Wrap the raw sheet data in the prompt.
  - Ask the model to analyze the incoming equity data and determine an extremely flexible Long or Short position for **EACH AND EVERY stock** in the dataset (mass diligence).
  - For each stock, explicitly ask for the "primary diligence aspect" that needs to be explored (e.g., verifying specific sector channel sales via primary calls).
- Save the model's exact response (an array of positions for all stocks) to `thought_process_log.md`.

## Step 4: Primary Research Target Generation (Queue Append)
- When you receive the mass diligence array from Nemotron, execute `lindy_handoff.py` securely using `gspread` to append **A NEW ROW FOR EACH STOCK** into the tracking sheet.
- **Google Sheet ID:** `1sH3zh2R2eUWsGFZr4oLe6hV5W47ulr_5JJzhFydcjTM`
- **Tab Name:** `Pipeline Queue`
- **Columns to Map:** `ticker` | `company` | `sector` | `reason` | `status` (Set to `pending`).
